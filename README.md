# 수업용 실시간 워드클라우드

- `index.html` 학생 참여 화면, 메신저형 (`?c=참여코드`로 바로 들어옴)
- `teacher.html` 교사 화면 (수업 만들기, 질문 관리, 말풍선 워드클라우드, QR, 사진 저장)
- 데이터는 Supabase 프로젝트 `bxydptizntolzhaonbgj`의 `wc_` 테이블에 저장
- 교사 권한은 수업마다 만들어지는 관리 키로 확인. 관리 키는 교사 브라우저와 "관리 링크"에만 들어 있음

## 올리는 방법
폴더 안 파일을 그대로 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 된다. 빌드 과정 없음.
